# Group Help feature checklist

This is a planning checklist for Hope Hub's group-management bot. It is documentation, not source code.

- Roles and permission hierarchy
- Custom roles
- Moderation commands
- Channel-user moderation
- Anonymous administrator support
- Bot help and bot clone support
- Time-zone and language settings
- Rules, welcome and goodbye messages
- Anti-flood, anti-spam, alphabet checks and captcha
- Content checks, media blocks, anti-NSFW, warns, night mode and link policy
- Approval mode, message deletion, topics and banned words
- Recurring messages, member management, masked users and discussion groups
- Personal commands, stickers/GIFs, message-length settings
- Log channel, staff group, group statistics and command permissions
- User-data removal and privacy controls
